# 翡翠圣城 v2 — DQ 式城市规划

> 学习对象：《勇者斗恶龙》(Dragon Quest) 系列的城市设计语言
> 配套实现：`src/engine/city/`（NPC 名单 / 对话状态机 / 闲逛 AI）

---

## 一、DQ 城市设计逻辑分析

| DQ 设计原则 | 核心思想 | 本作对应 |
|---|---|---|
| 单环动线 | 一条主街串起全部设施，玩家沿路走完即体验全部功能 | 十字大道 + 中央广场枢纽，设施分布在四象限门口 |
| 旅馆 | 付费全额回复（经典 8G/人） | 旅店老板娘玛莎：12 绿宝石全回复+药水 |
| 教堂 | 免费复活/净化/存档 | 牧师莎莉：免费治愈+回蓝（复活由本作死亡流程承担） |
| 武器/道具店 | 装备成长循环 | 铁匠/附魔师/炼金师 → 打开营地工坊页签 |
| 酒馆情报 | 吟游诗人/醉汉的传闻指向隐藏要素 | 吟游诗人小薇 + 行商布诺：传闻台词暗示生态传送门/隐藏神龛 |
| 城主/王座 | 主线发布与进度确认 | 城主奥德里克：按进度发布主线指引 |
| NPC 双状态台词 | 剧情事件前后台词不同，每句都有信息量 | 三状态：出发前 / 首胜领主后 / 通关后 |
| 可破坏瓦罐 | 破坏民宅木桶获得零钱（DQ 传统艺能） | 已有 barrel/urn 破坏物体系 |
| NPC 走动 | 城民在街上来往，城市"活着" | NpcWanderAI：以家为锚点的随机漫步 |

**核心体验目标**：进城 → 沿主街被 NPC 搭话 → 旅馆歇脚 → 工坊强化 → 酒馆听传闻 → 带着情报出城。

## 四、服务与经济

| 服务 | 执行 | 经济意义 |
|---|---|---|
| inn_rest | 扣 12 绿宝石 → HP/MP 全满 + 药水+1（上限5）；余额不足则被拒 | 金币消耗口，鼓励刷荒原 |
| heal_blessing | 免费 HP/MP 全满 | 新手保底（DQ 教堂免费精神） |
| open_camp_* | 打开营地工坊对应页签 | 复用现有 CampHubModal，零新 UI |
| class_transfer | 打开转职弹窗 | 复用 onOpenClassMaster |
| rumor | 追加一条传闻台词 | 引导隐藏内容：生态门/瞭望塔/水洼宝箱/北门地牢 |

## 五、闲逛 AI（NpcWanderAI）

- 以家（初始岗位）为锚点，半径 2.5 格内随机选可走目标格
- 移速 1.1 格/秒，走 1-3 格歇 2-5 秒；永不走进障碍/水/门
- 玩家靠近（<1.5 格）时暂停走动面向玩家，对话更有"被搭话感"
- 城市闲逛 tick 只在 `zoneType === 'town'` 时运行

## 七、NPC 人生模拟模块（`src/engine/sim/`）

> 目标：NPC 拥有自己的思考、逻辑与人生。规则大脑先行，**接口即为 LLM 接缝**——
> 未来把"感知快照"投喂给模型、由模型返回决策，替换 `RuleBrain` 即可，引擎零改动。

### 7.1 架构分层

```
WorldContext(时间/玩家/走位函数)
        │
NpcLifeSimulation（运行时：需求衰减 → 大脑决策 → 动作执行 → 记忆写入）
        │ 依赖注入
NpcBrain 接口 ──┬── RuleBrain（现在：日程 > 需求 > 随性的效用决策）
                └── LlmBrain（未来：buildAgentSnapshot() 的 JSON → 模型 → NpcDecision）
```

### 7.2 内心世界四要素

| 要素 | 内容 | 表现 |
|---|---|---|
| 需求 needs | energy 精力 / social 社交 / coin 钱袋 | 低精力会提前回家睡觉；低社交会主动凑近玩家 |
| 日程 schedule | 每人四时段（清晨工作/正午/黄昏休闲/深夜睡觉），按职业定制 | 吟游诗人正午广场演出、守卫通宵值岗、小孩下午采花 |
| 记忆 memory | 情景环（最近 8 条）：与玩家交谈/付费/治愈、世界事件（领主被击败） | 台词引用记忆："昨天你才来过" |
| 关系 relationship | 亲密度 affinity：交谈+1、被治愈+2、住店+3，随时间缓慢遗忘 | 里程碑台词：初次见面/老主顾/挚友 |

### 7.3 LLM 接缝约定（未来接入）

1. `buildAgentSnapshot(agent)` 输出可序列化 JSON：身份、日程、需求、心情、最近记忆、对玩家关系、周围感知
2. `NpcBrain.decide(snapshot)` 返回 `NpcDecision { action, sayLine? }`——LLM 版实现只做"快照→提示词→模型→JSON→动作"的翻译
3. 台词状态机（DialogueSystem）继续负责剧情主线，模拟层台词只负责"生活感"，两层并存

### 7.4 昼夜节律

一天 = 8 分钟现实时间（0-0.25 清晨 / 0.25-0.5 正午 / 0.5-0.75 黄昏 / 0.75-1 深夜）。
深夜城市街道空无一人（各自回家睡觉），只有守门卫兵罗兰仍在南门值岗；旅店深夜仍可投宿。

## 八、野外冒险者（复用玩家骨骼框架）

> NPC 与玩家使用**同一套 GoodSmile 骨骼渲染管线**——他们看起来就是"另一个冒险者"。

- **`AdventurerActor`**：`createAdventurerEntity` 产出 Player 形状的伪玩家（随机职业+`classSystem` 初始装备），位置/朝向/攻击动画全部走玩家管线
- **`adventurerAI`** 状态机：`roam 漫游 → hunt 狩魔（真实伤害走 damageEnemy 管线，掉落/任务计数生效）→ loot 搜刮 →（10% 战斗负伤）rescue 求救`；kind/brave 性格靠近玩家时 `join_offer` 想加入 → 点击后 `follow` 跟随并协助攻击
- **`AdventurerRenderer`**：友方实体直接调 `renderFigurine`；**敌对掠夺者**是真正的 Enemy（可被攻击、走怪物 AI、有掉落），通过 `defId === 'wandering_bandit'` 触发骨架渲染覆写——外形仍是人形冒险者
- 生成：荒原+六大生态区 1-2 位；其中 15% 出生即负伤（野外求救事件源）；救援成功获绿宝石谢礼
- 图鉴第 101 号：`wandering_bandit 荒野掠夺者`（illager 族，袭击玩家）
